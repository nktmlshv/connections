# Connections
##### Технологии: Java, Spring Boot, Spring Data JPA, MapStruct, OAuth2, Git

- Микросервис, разработанный как часть платформы Modula — no-code решения для интеграции различных внешних сервисов (например, «сообщение в Telegram → строка в Google-таблице»).
- Сервис отвечает за хранение и обработку подключений пользователей к внешним платформам. Включает ручную реализацию протокола OAuth2 (authorization code flow), с возможностью обновления токенов.
- Архитектура построена на расширяемой иерархии сущностей с использованием стратегии JOINED в JPA, что позволяет легко добавлять новые типы подключений (OAuth2, API Key, Basic Auth и другие).
- Для преобразования между слоями DTO и Entity применяется MapStruct с поддержкой полиморфизма по полю authType. Проект масштабируем и покрыт тестами.
