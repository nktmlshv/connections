# Connections
Модуль для хранения подключений к внешним сервисам для платформы Modula. Modula - это no-code решение для создания интеграция между разными сервисами. Например, пришло сообщение в Telegram -> создать строчку в Google-таблице.

- Ручная реализация протокола OAuth2
- Spring Boot
- Spring Data JPA
- MapStruct
